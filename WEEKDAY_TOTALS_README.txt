TYRETRACK — WEEKDAY TOTALS ROW

The second bottom row shows Monday-Friday for the current Brisbane week.
Each block shows its date and production tyre total. Today is highlighted in
blue; completed days are green; future days show a dash. The displayed date
range advances on Monday. The previous week's data stays in stored reports.
The row fills from existing production history immediately after updating.
It uses the same OAK source and 05:00-17:05 shift as the hourly reporting.
Video/manual test counts do not populate the production daily row.
This update preserves the 640x360 live view and original-preview fallback.

This ZIP is complete GitHub-ready source, not a prebuilt Windows executable.
Extract and overwrite matching source files in the repository, then run the
Windows build workflow. Install its newly built portable release with the app
closed. Preserve the site's data, reports and private configuration.
The existing data folder is needed to show earlier days; do not delete it.
