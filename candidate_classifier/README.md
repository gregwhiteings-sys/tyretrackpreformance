# New classifier candidate: observe only

This ONNX is a crop classifier, not a replacement tyre detector or OAK blob.
It is the owner-supplied 27 November 2026 automatic-training result, tested on
a separate 25 November clip. Its labels were generated by the old visual model.
Agreement does not prove independent real-world accuracy. Passenger and SUV/4x4
are supported; no truck examples were supplied. See metadata.json for the hash,
class map and preprocessing. No training images or private review database are
included in this repository.

The application samples one existing crop per actual production OAK count,
asynchronously on a single CPU inference thread. It never changes the production
class, count, overlap correction, foreign alert or live video label. The original
detector and OAK blob remain the production models.
