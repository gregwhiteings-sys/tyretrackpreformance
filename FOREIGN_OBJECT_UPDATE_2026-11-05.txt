TYRETRACK MONDAY FOREIGN-OBJECT UPDATE

The OAK-D S2 (RVC2) foreign-object pipeline loads the Monday model from
rvc2_models/foreign/foreign_object.blob. The 416x416 input is raw planar BGR.
The blob reverses the channels to RGB and divides by 255. Output is one
foreign_object class in the YOLOv8 tensor [1, 5, 3549].

This is the Windows source package. Build it on Windows x64 with Python 3.12
using BUILD_WINDOWS.py. Live camera and conveyor alarm tests are pending.
The Monday conveyor ROI has not been wired into the app in this update.
