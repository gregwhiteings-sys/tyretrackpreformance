MONDAY SETUP
COUNTING -> Belt size assist -> Compare only (recommended). This is the initial
mode on the first launch of this update, including an existing installation.
The width begins at the previously saved value, or 1100 mm if no setting exists.
1100 mm is an ASSUMPTION, not a physical measurement. Advanced belt edges retain
the previous calibration. Show belt edges during setup. No exact tyre sidewall
size is read; millimetres refer to estimated outside diameter.

TODAY'S CLASSIFICATION COMPARISON
The dashboard refreshes every 30 seconds. It shows original OAK class totals,
the size-assisted proposal (including visual fallbacks), direct size-only
candidates, and the class actually used for production. Passenger, SUV/4x4
and Unclassified stay separate. Only comparison records captured by this build
are shown; older counts are not backfilled. Each production tyre counts once.
A usable measurement can be attached AFTER its count, when it reaches a clearer
middle view. The original production count/class is preserved. Records without
a usable measurement are saved when their track retires or counting stops.
Display/review totals may therefore lag counts briefly. The proposed result is
not a guarantee of accuracy. A size-only disagreement differs from an assisted
proposal change: strong visual votes still win the assisted proposal.

SIMPLE MODES
Compare only: original class supplies production; both proposals are recorded.
Use size assistance: weak visual votes may use size evidence available AT COUNT
TIME. A later size estimate is recorded as a proposal, never a rewrite of an
already committed production count. Off: original classifier only.
Both classifiers operate on the same detected/tracked tyres; this does not test
missed tyre detections. Overlaps, tilt, clipping, measurement uncertainty, camera
movement and the guessed belt width still limit size accuracy.

DAILY FILES
Private local folder: data/classification_review/
- reviews.sqlite3: independent review database, not the production count DB.
- images/: count/measurement crops and clean foreign inference images.
- daily/YYYY-MM-DD_summary.json and _summary.csv: original/proposed totals,
  direct size candidates, coverage and human-marked foreign false alerts.
Daily summaries refresh after 60 seconds of an idle review queue and at clean
shutdown; a human review also refreshes that day's summary. The dashboard reads
the database directly. Records persist across normal restarts. Back up this
folder separately: the older production-count backup does not include it.
No automatic deletion/retention is enabled in this update; monitor disk space.

HUMAN REVIEW
COUNTING or FOREIGN -> Open daily comparison and alert reviews.
Choose a Brisbane date and Production / Live test / Video replay scope.
Select a row to inspect its image and original prediction. For tyres record
Passenger, SUV/4x4, Truck or Unsure based on physical/site evidence. For foreign
alerts choose Confirmed foreign object / False alert / Unsure. False alert
reasons: normal tyre mistaken for metal/rim, belt join, shadow, other. Use notes
for the actual object and reviewer. Review changes keep a history. Reviews do
not modify counts, reset alarms or change model weights.
Original boxed incident snapshots/CSV/JSON continue to be saved as before.
New alerts ALSO save an unboxed inference image, confidence, box, model hash,
frame sequence and recording reference when a recording is active. Older
incidents remain in data/foreign_incidents; this screen does not import them.
A referenced MP4 may not exist until the recording segment is finalised. Open
recording folder and use the timestamp/frame reference; exact clip seek is not
implemented. No extra before/after video clip is generated by this update.

EXPORTS
CSV exports all records for the chosen date/type/scope, including reviews.
Reviewed evidence ZIP exports human-reviewed cases only; unreviewed and unsure
are excluded. It contains images plus a manifest, NOT ready-to-train YOLO labels.
A false alert is NOT automatically an empty-label negative: the full image may
contain another real foreign target. Review/annotate every target before training.
Never suppress all tyre/metal overlaps; a real rim can sit inside a tyre.

RECORDED VIDEO
Video test uses the same size helper and exports classification_comparison.csv
beside test_summary.json and annotated_test.mp4. Open this video's classification
comparison in the video tester. Replay records stay in that test output folder,
not production history. CPU detector outputs can differ from OAK blob outputs.
