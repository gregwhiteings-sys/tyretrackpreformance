What viewers see
A compressed still of the operator dashboard, including the conveyor preview,
statistics and hourly/weekday blocks. A timestamp is shown in Brisbane time.
Tap/click to open full size. It is not streaming video. After 90 seconds without
a fresh capture the image is marked paused and remains dated as last received.
Anyone with the public link can view it. Administration panels are excluded
using an allow-list of operator widget pixel regions. The camera view can still
show whatever is physically within its field of view.

Performance and storage
The existing 30-second dashboard capture is reused. JPEG compression, resize
(maximum 1280x960, aspect ratio preserved) and upload run in a background thread.
JPEG quality 65; maximum 512 KB. Four-second network timeout, no overlapping
image jobs. Offline replay/manual tests are not published. Image sharing uses
the existing private uploader credential and does not open any PC ports.
The server retains only the latest image. Turning sharing off stops future
uploads; the last published image remains visible and later becomes stale.
