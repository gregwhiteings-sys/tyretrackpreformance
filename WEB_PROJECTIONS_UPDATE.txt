WEB PROJECTIONS UPDATE

estimated tonnes, replacing the old daily target. It also shows public system
health and hourly activity summaries. Missing values remain clearly marked as
waiting for the updated onsite app; no projections are invented from incomplete
web history. Actual totals and existing sharing settings remain unchanged.

Build/install this ZIP through the existing GitHub Windows workflow. Keep the
existing connection file and normal web sharing enabled. No new connection file
or sharing permissions are required. The new values will arrive automatically.

are omitted from new uploads. The webpage labels stale overall updates.
